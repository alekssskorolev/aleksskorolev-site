# Личный сайт Алексея Королёва

Планируемый домен: https://aleksskorolev.ru

## Страницы
- `/` — временная главная страница без вымышленных контактов.
- `/duhovny-tupik/` — согласованная статья, тёплый фон и прежнее оформление.
- `/master-class/` — согласованный продажник с каруселью из шести примеров.

Статья ведёт на продажник внутри этого сайта. Покупка остаётся в Telegram-боте: https://t.me/aleksskorolev_bot?start=site_mk
Тест и его репозиторий не изменены, тест остаётся на egotest.ru.

## Публикация
GitHub Pages: ветка `main`, папка `/ (root)`, источник `Deploy from a branch`.
Для частного репозитория доступность Pages зависит от тарифа GitHub. Не менять публичность без согласия владельца.

## Перед подключением домена
1. Проверить действующий хостинг и сохранить реальные страницы `/oferta` и `/policy`. Они НЕ включены в этот перенос: при подготовке HTTPS-соединение с действующим доменом завершалось ошибкой, тексты не получены. Это не доказывает, что страницы не работают у владельца.
2. Убедиться, что юридические документы относятся к этому продукту. Не сочинять и не заменять их текст.
3. Добавить custom domain `aleksskorolev.ru` в настройках Pages и настроить DNS REG.RU; MX/TXT и почту не менять.
4. Дождаться сертификата и включить Enforce HTTPS. Проверить главную, статью, продажник, юридические ссылки и переход в бот.

CNAME намеренно пока не добавлен. DNS и настройки текущего домена не менялись. Старые страницы egotest.ru не удалены.

Сторонняя аналитика не добавлена. Изменения содержимого статьи и продукта не выполнялись.
